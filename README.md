# Bluegrass Commercial Door & More Website

Production-ready static marketing website for Bluegrass Commercial Door & More in Bowling Green, Kentucky.

## Included

- Responsive, photo-led layout for phone, tablet, and desktop
- Guided door finder with a quote-form handoff
- Validated quote request that prepares a detailed email
- Scripted customer help panel with quick answers
- Mobile navigation, click-to-call links, and a mobile contact bar
- Project gallery with an accessible photo viewer
- LocalBusiness structured data and social metadata

## Local viewing

Serve the repository root with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in a browser.

All website assets use relative paths so the site works from a GitHub Pages project subpath.
